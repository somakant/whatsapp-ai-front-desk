# Contributing to whatsapp-ai-front-desk

Thanks for helping! Every contribution counts, from a typo fix to a new feature.

1. **Find or open an issue.** Issues labelled `good first issue` are small and well scoped. For anything big, open an issue first so we can agree the approach.
2. **Fork, branch, change.** Keep pull requests focused on one thing.
3. **Run the tests** with `npm test` and add a test for any new behaviour.
4. **Open the pull request** with a short description of what changed and why.

Questions? Start a [discussion](https://github.com/somakant/whatsapp-ai-front-desk/discussions). Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
